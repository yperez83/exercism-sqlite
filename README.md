# Exercism - SQLite Track

Welcome to my repository for solving **Exercism** coding exercises using **SQLite**. This repository tracks solutions, evaluations, and relational database queries implemented across various challenge domains.

---

## 📂 Repository Structure

Each exercise is organized in its own directory containing the solution script, instructions, and test evaluation reports:

```text
exercism-sqlite/
├── etl/                # ETL pipeline exercise (JSON parsing & transformation)
├── sublist/            # Determining relational status between given lists
├── wordy/              # Text-based math expression evaluator
├── README.md           # Master repository documentation
└── ...
```
## 🛠️ Environment & Tools
- Database Engine: SQLite 3 (utilizing advanced JSON and window functions)
- Testing Methodology: Exercism SQLite test runners and custom assertion setups
- Version Control: Git & GitHub
